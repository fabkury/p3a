# RUN-20260828-01 — baseline soak, ABORTED after 5 min (instrument defect)

- Diag build e882120c, playset "Work mix", 13:48–13:53 local, 5630 frames.
- What happened: an artwork (generation 9, 50 ms frames) needs 42–64 ms per
  frame to produce (decode 25–46 ms + upscale 17 ms). Lateness climbs ~10 ms per
  frame to the 250 ms resync threshold and resyncs every ~5.6 s. The analyzer
  filed these 887 frames as out-of-scope overrun (correct), but the firmware
  reporter printed a full `JTR|` block on every resync (rate-limited to 1/5 s),
  flooding UART at 115200 baud, which itself can perturb timing.
- In-scope stalls: 2, both the pre-soak `cpu1` provoke still in the ring
  (puller started at seq 0). Fixed: puller `--from-head`, stats reset at start.
- Fix shipped: firmware EMA of producer time per generation; producer-explained
  lateness is counted (`stalls_overrun`) but never reported on UART.
- Observation for Phase 6: for chronically slow artworks the 250 ms resync
  policy produces a visible skip every few seconds instead of a uniform slowdown.
