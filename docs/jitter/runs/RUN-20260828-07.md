# RUN-20260828-07 — "AFTER" soak: aligned PSRAM SD buffers (065d6c90) — ZERO in-scope stalls in 1.1 h

- Diag build 065d6c90 (+span marks), "Work mix", 15:50–16:57 local, 54 251 frames.
